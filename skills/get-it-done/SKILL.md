---
name: get-it-done
description: Use only when "get it done" is specifically mentioned.
---

Take the task to a pull request the user can merge, without their help along the way.

Decide reversible things yourself. Ask before anything that can't be undone, like merging, deploying, deleting data or sending messages. If you're blocked, say what blocks you and what you need.

Before handing off:

1. Rebase on the latest base branch.
2. QA it.
3. Demo it, and add the demo to the PR.
4. Get CI green.
5. Assess merge risk.

Hand off with the demo, the merge risk, and what isn't done.
