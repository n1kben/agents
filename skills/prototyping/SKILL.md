# Prototyping

## Build options

Before implementing the requested UI, inspect the existing app and prototype three options by default.

Give each option a short name. Make them structurally different, not cosmetic variations. Use the app's preview system when it has one. Otherwise create a throwaway sandbox with the same stack. Keep the prototype separate from production code.

## Show the options

Run and check all the options in the preview. Fix anything that prevents a fair comparison.

For each option, provide a screenshot, instructions for trying it, and its pros and cons. Recommend one and explain why. Wait for the user's choice.
