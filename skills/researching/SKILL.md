# Researching

Search short and broad first. Long, specific queries tend to come back empty, so see what is out there and then narrow.

Go to the source: the docs and changelog for the exact version in use, the code, the issue tracker. A blog post or an answer that says "just set this flag" is a lead (not evidence). Who wrote it? Where did they get it? Trace it back to where it first appeared before you trust the page.

Look for what would prove you wrong. Two sources agreeing does not mean much if one copied the other.

Stop when the claim is settled or new searches keep turning up the same thing. If reading cannot settle it, spike it.

Cite a source for each claim, and check that it actually says what you claim.
