# Outline-first writing

Work through the writing in this order:

1. Create an outline. Keep working on it until someone can understand the piece from the outline alone.
2. Use the outline to pitch the paragraphs for each point. If the pitches reveal a gap, revise the outline.
3. Draft from the pitches. Use brief, direct, conversational language.
