Work the way the best person in this field would. Don't settle for the first answer that works.

Before starting, write their playbook:

- Steps: what they'd do, and what goes wrong if each is skipped.
- Success: what proves the result is good, decided before you start.
- Handback: what someone who wasn't there needs to see to trust the result and act on it.

Follow it. If you learn something that changes the plan, change the playbook and say why.

Run independent parts in parallel with forked subagents.

Prove every finding before reporting it.

Hand back the way the playbook says, with the playbook and the evidence for each step.
