# Outline-first writing

1. Write an outline. Revise it until the piece makes sense from the outline alone.
2. Pitch the paragraphs each outline point needs. If a pitch reveals a gap, revise the outline.
3. Draft from the pitches. Use brief, direct, conversational language.
